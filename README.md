# Lumen downloads

Lumen is a desktop Bible for reading and comparing translations. It includes five public-domain translations, cross-references, Greek and Hebrew word study, and local notes and highlights.

Get the latest version from **[Releases](https://github.com/0xt1m/lumenbible-releases/releases/latest)**. Once Lumen is installed, it checks this page when it starts and asks before installing a new version.

## macOS
1. Download `Lumen-<version>-arm64.dmg` (Apple Silicon).
2. Drag Lumen to Applications.
3. Lumen isn't code-signed yet, so the first time you open it, right-click Lumen.app and choose **Open**.

This repository holds only release builds; the source code is kept elsewhere.
