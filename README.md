# nxtbible downloads

nxtbible is a desktop Bible for reading and comparing translations. It includes five public-domain translations, cross-references, Greek and Hebrew word study, and local notes and highlights.

Get the latest version from **[Releases](https://github.com/0xt1m/nxtbible-releases/releases/latest)**. Once nxtbible is installed, it checks this page when it starts and asks before installing a new version.

## macOS
1. Download `nxtbible-<version>-arm64.dmg` (Apple Silicon).
2. Drag nxtbible to Applications.
3. nxtbible isn't code-signed yet, so the first time you open it, right-click nxtbible.app and choose **Open**.

This repository holds only release builds; the source code is kept elsewhere.
