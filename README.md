# nxtbible downloads

nxtbible is a Bible for reading and comparing translations. It includes five public-domain translations, cross-references, Greek and Hebrew word study, and notes and highlights saved on your computer. It also runs in the browser at **[nxtbible.com](https://nxtbible.com)**.

Get the latest version from **[Releases](https://github.com/0xt1m/nxtbible-releases/releases/latest)**. Once installed, nxtbible checks for new versions when it starts and asks before installing one.

| System | Download | Notes |
| --- | --- | --- |
| Mac with Apple silicon (M1 or later) | `nxtbible-<version>-arm64.dmg` | Signed and notarized by Apple. Drag nxtbible to Applications; updates install there. |
| Windows 10/11, 64-bit | `nxtbible-<version>-x64-setup.exe` | Not code-signed yet. If SmartScreen warns "Windows protected your PC", choose **More info › Run anyway**. |
| Linux, 64-bit | `nxtbible-<version>-x86_64.AppImage` | Make it executable (`chmod +x`) and run it. It updates itself in place. |

This repository holds only release builds; the source code is kept elsewhere.
